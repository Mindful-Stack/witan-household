# Tribal knowledge starter

This is where captured learnings live — single-purpose files that record non-obvious behaviour, gotchas, or edge cases discovered during real work. Use the `/lore:learn` command (Lorekeeper) to add new entries.

Each learning has frontmatter capturing:

- `confidence` — `verified` (developer-confirmed) or `hypothesis` (unvalidated)
- `source` — `developer-input` or `agent-proposed`
- `date` — when it was captured

The body is free-form: explain what, why, and when-it-matters.

Replace this placeholder file with real learnings as they accumulate.
